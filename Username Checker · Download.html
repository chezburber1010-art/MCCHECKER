What you get

Get running in a minute

  1. Install Python 3.8+ from python.org. On Linux also run sudo apt install python3-tk.
  2. Unzip the download anywhere you like.
  3. Launch it: double-click run.bat (Windows) or run.command (Mac), or run python mc_checker.py. Then enter your access code on the first screen.

Free to download, unlocked with an access code

  1. Download the app above. That part is free for everyone.
  2. Get an access code from the seller (). It’s a long code that starts with UCK1-.
  3. Paste it on the app’s first screen, or open the key file you were sent. The code is checked on your own computer, so the app works offline.

Check only, nothing sneaky

🔒
